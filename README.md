# Big Data: Hive Queries

SQL-запросы в Apache Hive для анализа больших данных.

## Задача
Проанализировать таблицу пользовательских событий: активность по странам, топ событий, воронка.

## Стек
- HiveQL
- HDFS
- Apache Hive

## Задания
1. Создать внешнюю таблицу
2. Загрузить данные
3. Написать 5 аналитических запросов
4. Оптимизировать через партиционирование
